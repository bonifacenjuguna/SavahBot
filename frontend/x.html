SavahBot privacy policy

Last updated: November 2026

SavahBot is a private moderation and utility tool for YouTube live chat. It is built and used by one person, its owner, for the owner's own channel. It is not offered to the public and has no other users.

What the app accesses

When the owner connects their Google account, SavahBot asks for one permission: the YouTube scope youtube.force-ssl. It uses that permission, on the owner's channel only, to:

  • find the owner's current live broadcast;
  • read the live chat messages of that broadcast, including each chatter's public display name and channel ID;
  • delete messages, time out or ban chatters, and post chat messages, when the owner approves it or has switched on automatic moderation.

What is stored

The owner's sign-in token, recent chat messages and moderation decisions are stored in a private database that only the owner's deployment can reach. Chat history is deleted automatically after a retention period the owner controls.

What is not done

  • No data is sold, shared with third parties or used for advertising.
  • No data is used to train artificial intelligence or machine learning models.
  • No human other than the owner reads the data.

Google API Services

SavahBot's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can disconnect Google from the dashboard Setup page, or revoke access at any time at myaccount.google.com/permissions. Removing the deployment's database deletes all stored data.

Questions can be sent to the contact email shown on the Google sign-in screen for this app.
